# SP QC 대시보드 (Apps Script) 소스 보관

"SP QC 대시보드 마스터" 구글 시트에 바인딩된 Apps Script 웹앱 소스.
대표(박보민)가 2026-08-06 채팅으로 전달한 사본. 배포는 Apps Script 편집기에서
파일 교체 → [배포 관리 > 새 버전]으로 진행한다.

## 파일 구성 (Apps Script 프로젝트)
- Code.gs        — 서버 전체 (v2.9 기준, 아래 저장됨)
- Index.html     — 성우 페이지 (전달받음, 이번 작업 수정 대상 아님 → 미보관)
- EngIndex.html  — 엔지니어·검수자 페이지 (전달받음, 수정 대상 아님 → 미보관)
- PubIndex.html  — 출판사 파트너 페이지 (전달받음, 수정 대상 아님 → 미보관)
- AdminIndex.html — 관리자 대시보드 (★ 개선 대상, 수신 대기 중)
- Login.html     — 아이디/비번 로그인 랜딩

## 이번 개선 목표 (대표 요청: "모든 오디오북 진행사항 한눈에, 지금은 너무 복잡")
1. 관리자 홈에 전 도서 1줄 요약 보드 (도서 | 단계 | 다음 액션 | 마감)
2. 알림 정리 — '판정 대기'(75건씩 쌓임)를 홈 알림에서 분리, 진짜 새 소식만
3. 도서 관리 카드: 조회 요약 우선, 편집 폼은 접기

## 관련 서버 함수 (Code.gs)
- buildAdminPayload_() — 관리자 데이터 페이로드
- adminAlerts_()       — 홈 알림 목록 생성 (pub/rec/wait 3종. wait가 알림 폭주 원인)
- alertLogForAdmin_()  — 출판사 업데이트 알림 로그 (미확인만, 최대 50)
