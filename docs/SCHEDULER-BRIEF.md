## 1. 지금 미완료 (두투 q1 = 긴급·중요, 2026-08-06 기준)
- 신용카드 신청 (7월부터 이월 — 오래 밀린 항목)
- 북프린 픽업
- 오디오편집 자동화
- 미생물 이주형 업로드 (『미생물로 쓴 소설들』 엔지니어 이주형 업로드 건)
- 지방세, 세금
- 박근아 성우님 대본 전해주기
- (오늘 목록 = 위 6건 전부)

## 2. 대시보드 쪽 대기 업무 (QC 시스템, 2026-08-06 기준)
- 판정 대기 75건 — 대부분 과거시트 이관분. 도서별: 도시 42건 등
- 재녹음 도착 2건 반영 확인
- 출판사 미제출 체크 13건 (성우선정·원고·타이틀·트레일러·초안검수·정산 중 미완료)
- 최근 완료: 황장미 검수자 연락·새 검수 배정·페이 (8/6 완료 처리됨)

## 3. 전략 과제 (두투 q2 — 중요·비긴급)
용민휠타 네이버스토어 / 스토리팝 오디오북 편집·출판 / 새로운 사업방향·골 설정 /
SP 카탈로그 / 자체 30분 오디오북 시리즈 / 피아노 동화 / 메타데이터 자동화(→ sp-metadata 스킬로 일부 해결됨)

## 4. 위임·대기 (q3) 및 백로그 (q4)
- q3: 뜨인돌 오디오북 유통, 원고 초안 검토, 원고 뽑기, 역사비평사 재업로드(제이매니저 오류)
- q4: 유튜브 포트폴리오, 기사·티스토리, 크몽 등록

## 5. 완료 이력에서 드러나는 반복 패턴 (4~8월 70여 건 분석)
1. **성우 관리 주간 루틴**: 샘플 요청→수령→출판사 전달→톤 컨펌→스케줄 잡기→페이 지불
   (예: 7/15 단가조절 전화, 7/16 박근아 페이, 7/24 성우 일정잡기, 7/30 성우스케줄)
2. **출판사 커뮤니케이션**: 전화 돌리기·이메일 답장·최종원고 요청·컨펌 메일 — 2~3일 주기
3. **체험 프로그램**: 월초 집중 (8/1~8/3 체험준비 11건 — 체험지·에어컨·빔·출석부·간식·녹음준비 등).
   체험 전날 준비 체크리스트가 사실상 고정 세트임 → 템플릿화 가치 높음
4. **행정·재무 월간**: 월세(월초), 지급명세서, 지방세, 견적서(포천중학교, 시하기획 등)
5. **시스템 구축**: 7/21 대시보드 구축·전달, 7/24 아이디 배포 — 현재 이 세션에서 개선 진행 중
6. **미루는 경향**: 마감 없는 개인 행정(신용카드, 세금)이 수 주씩 이월됨 → 리마인드 필요 유형

## 6. 스케줄러 에이전트 권장 동작
- 아침 브리핑: q1 + 대시보드 판정 대기/새 소식 수 + 오늘 캘린더(연결 시) 통합
- 체험 예정일 감지 시 "체험 전날 체크리스트"(5-3 세트) 자동 제안
- 2주 이상 이월된 q1 항목은 별도 강조 (현재: 신용카드 신청)
- 성우 녹음 후 페이 지불 태스크 자동 생성 (녹음기록 탭 연동)
